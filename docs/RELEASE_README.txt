Pixel Cosmos Studio - Windows

Extract the whole ZIP, then open PixelCosmosStudio.exe.
Keep PixelCosmosStudio.pck beside the executable.
No Godot editor installation is required.

Choose Planets or Space, adjust the controls, then export your asset.
Use the Animation tab for PNG frame sequences or editable-noise context.
Settings switches between English and Simplified Chinese.
Presets are saved on this device; export JSON copies to keep a backup.

Source and full documentation:
https://github.com/JupiterTheWarlock/PixelCosmosStudio
