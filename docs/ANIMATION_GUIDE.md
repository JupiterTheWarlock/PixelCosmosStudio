# 动态噪声与循环动画

右侧“动态”页分别设置云层形变、海水流动、气态条带扰动或星云演化。底部“播放噪声”控制播放；拖动时间轴会暂停，回到开头可检查第 0 秒。自转/云壳旋转仍是另一组独立控制。

循环时长越长，变化越慢；每轮变化次数越多，变化越快。变化幅度为 0 或关闭对应动态时，图层静止。海岸、陆地和天空星点保持固定。所有噪声都在球面方向上计算，不按天空盒各面单独随机。

## 导出动画

“导出循环动画”输出：

- 第 0 秒的标准静态资产（GLB 或天空图片），用于建立材质和场景。
- frames/0000、0001…：每帧的六面本色 PNG，以及启用云层时的六面透明云图。天空为 sky_px.png 等六面图。
- animation.json：完整参数、算法版本、算法文件哈希、时长、帧数、帧率、面顺序、完成标记。
- noise_core.gdshaderinc：生成这些帧的实际参考算法。
- IMPLEMENTATION_CONTEXT.md：同一套配置和算法组织成的 Agent 实现说明。
- stars-special.png：算法引用的星形图案。

导出包含完整一轮噪声变化，不包含模型自转、云壳额外旋转、灯光或相机运动。PNG 是本色，保持实时光照。动画不会变成 GLB 内置动画轨道；游戏需要逐帧切换材质纹理。静态导出固定为第 0 秒，不是暂停时刻的截图。

默认 24 秒 / 96 帧，即 4 帧/秒；预览按显示帧率连续计算，因此导出更跳帧。需要更顺滑时提高帧数，比如 24 秒 / 288 帧为 12 帧/秒。界面显示图数、帧率与未压缩大小；PNG 压缩后的体积依内容变化。不要一次加载全部高分辨率帧后假定显存占用等于磁盘文件大小。

停止导出后保留部分文件，animation.json.complete 为 false，不能当成完整动画。

## 播放约定

播放帧索引为 floor((time_seconds % duration_seconds) / duration_seconds * frames)。帧 n 对应 n * duration_seconds / frames 秒，不重复导出结束时刻。最近邻时间采样保留像素画风；可选择帧间混合，但会产生中间色。图片为 sRGB 本色、直接透明度，数据/遮罩解释见导入说明。

球体的 Surface 有六个表面材质，按 px,nx,py,ny,pz,nz 替换本色纹理；CloudShell 同理并保留透明裁切。星环不参与噪声动画。天空使用相同顺序，按方向采样，避免引擎的 Cubemap 顺序差异。

体素模型当前使用顶点颜色，没有适用于动画序列的 UV。播放体素动画时，需要使用物体局部位置的归一化方向采样六面帧图，并替代顶点本色；不能只替换普通材质的纹理就认为接好了。对应方向公式见 IMPORT_GUIDE.md。

## 复制动态实现说明

“复制动态实现说明”包含当前全部参数、精确的噪声参考代码、时间/坐标约定、图层固定规则和算法哈希，供目标项目的 Agent 移植。它与动画导出调用同一个配置构建函数，不另外生成一套近似参数。

预览 spatial/sky shader 与离线 PNG 生成器都包含 noise_core.gdshaderinc。显式 noise_time 替代引擎 TIME；整数变化次数确保循环。移植时不要用其他引擎的默认噪声替换本算法。浮点精度、贴图分辨率、采样和色彩管理仍可能导致细小差异。

当前是云/海/气态/星云的视觉噪声动画，不是流体或大气物理模拟。此轮仅在 Godot 工具内验证，没有启动其他引擎。
